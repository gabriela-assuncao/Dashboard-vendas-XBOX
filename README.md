
# Dashboard-vendas_XBOX

Projeto de análise de dados desenvolvido inteiramente em Excel, focado na gestão, tratamento e visualização de métricas do ecossistema Xbox.



# 📌 Sobre o Projeto
Este repositório contém um projeto que transforma dados brutos de jogos e usuários em insights estratégicos. O projeto foi estruturado seguindo as melhores práticas de organização de dados (ETL), separando a base de dados dos cálculos e da interface visual.


# 🏗️ Estrutura do Arquivo
O projeto está dividido em quatro pilares fundamentais, conforme a organização das planilhas:

- Bases: Onde residem os dados brutos (Raw Data). A fonte da verdade do projeto.

- Assets: Elementos visuais, ícones e referências de design para manter a identidade visual do Xbox.

- Cálculos: A "engine" do projeto. Utiliza fórmulas avançadas para processar os dados, criar tabelas dinâmicas e métricas de suporte.

- Dashboard: A interface final interativa, com gráficos e indicadores (KPIs) para tomada de decisão.


# 🛠️ Tecnologias e Habilidades Aplicadas
Excel Avançado: Uso de funções complexas para automação.

- Data Cleaning (ETL): Tratamento de dados para garantir a integridade das análises.

- Data Modeling: Estruturação de tabelas relacionadas (Bases vs. Cálculos).

- UI/UX Design para Dashboards: Criação de uma interface intuitiva e visualmente alinhada à marca.


# 📊 Funcionalidades Chave

- Visualização de métricas de engajamento/vendas.

- Segmentação de dados para filtragem dinâmica.

- Design customizado focado na experiência do usuário.
